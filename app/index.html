Perguntas frequentes

Quais formas de pagamento aparecem?

Pix (simulado), cartão ou dinheiro no momento da entrega ou retirada. Nenhum dado de cartão é solicitado pelo site.

Onde ficam salvos os meus dados?

No próprio navegador, em um banco de dados SQLite local. Eles não são enviados para nenhum servidor e podem ser apagados no rodapé, em “Restaurar dados iniciais”.

Preciso criar conta para comprar?

Você pode montar o carrinho sem conta. Para finalizar o pedido e acompanhar o status, é preciso entrar ou criar uma conta.
